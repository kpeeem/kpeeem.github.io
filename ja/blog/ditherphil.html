DitherPhil は「写真」や「ファイル」から画像と動画を読み込みます。画面下のパネルでアルゴリズム、パレット、粒の大きさを変えながら、同じ画面で結果を確認できます。比較ボタンを押すと元の画像に切り替わります。

Bayer の行列は 3 サイズ。Atkinson、Floyd–Steinberg、Sierra Lite、点描も使えます。元の色を残すほか、パレットを選んだり、暗部と明部の色を指定したりできます。露出、コントラスト、彩度、色温度はディザリングの前に調整します。

Core Image と Metal が端末上で処理します。プレビューには縮小したフレームを使い、書き出しでは指定の解像度で描画し直します。PNG は透明度を保持でき、JPEG と HEIC は圧縮品質を調整できます。動画は音声付きの MP4 として HEVC または H.264 で書き出します。

SwiftUI で作ったエディタで、iOS と iPadOS 26 以降に対応します。

バージョン 1.1 では共有メニューから編集でき、動画をループ再生しながら調整できます。設定は名前付きプリセットとして保存できます。写真は書き出しをタップするとすぐに描画を開始します。結果は「写真」に保存でき、「ショートカット」の「ディザリング」アクションでも処理できます。
