Agent Meter は macOS のメニューバー常駐型ネイティブアプリです。Claude の 5 時間枠と週枠、Codex のリアルタイムの上限、Grok の週間プールを表示し、API の支出を集計し、セッション統計を集めます。読むのは Claude Code と Codex のローカルファイルだけで、Claude へのアクセスもテレメトリ送信もしません。

図1

図2ノッチには各エージェントの状況が出ます：プロジェクト、プロンプト、ターンの経過時間と結果。

図3Claude が許可を待つと、ノッチからカードが現れます。ターミナルに切り替えずに「はい」「いいえ」「常に」。

メニューバーでは上限の枠が 3 秒ごとに切り替わり、表示する項目は設定で選べます。統計にはセッション、トークン、1 年分のカレンダー、上限の履歴、隠れたバックグラウンド作業が並びます。同じ数値は Bluetooth LE で電子ペーパーの Claudometer にも届きます。

図4上限パネル：Claude、Codex、Grok、Z.ai と Kimi の Coding Plan をひとつの一覧に。

アプリはサンドボックス内で動き、~/.claude/projects と ~/.codex/sessions に読み取り専用でアクセスします。API キーは Mac 上の権限 0600 のファイルに保存され、通信するのはキーを追加したプロバイダーだけです。表示言語はシステムに合わせて英語・ロシア語・ポーランド語。

ソースとビルド：github.com/kpeeem/agent-meter
