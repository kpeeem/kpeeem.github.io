About

012026

Agent Meter is a native macOS menu bar app. It shows the Claude 5-hour and weekly limit windows, live Codex limits and the Grok weekly pool, tracks API spending and collects session statistics. It only reads the local files of Claude Code and Codex, never talks to Claude and sends no telemetry.

Fig. 2The notch shows what every agent is doing: project, prompt, how long the turn takes and how it ended.

Fig. 3When Claude waits for permission, a card pops out of the notch: Yes, No or Always, without switching to the terminal.

In the menu bar the limit windows cycle every three seconds, and the set is chosen in settings. Statistics cover sessions, tokens, a year calendar, limit history and hidden background work. The same numbers go over Bluetooth LE to the Claudometer, an e-paper display.

Fig. 4The limits panel: Claude, Codex, Grok and the Z.ai and Kimi Coding Plans in one list.

The app is sandboxed and gets read-only access to ~/.claude/projects and ~/.codex/sessions. API keys stay on the Mac in a file with 0600 permissions, and the network is used only for providers whose keys you added. The interface speaks English, Russian and Polish, following the system language.

Source and build: github.com/kpeeem/agent-meter
