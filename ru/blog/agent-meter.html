Agent Meter — нативное приложение для строки меню macOS. Оно показывает окна лимитов Claude на 5 часов и неделю, живые лимиты Codex и недельный пул Grok, считает расходы API и собирает статистику сессий. Приложение только читает локальные файлы Claude Code и Codex, не обращается к Claude и не шлёт телеметрию.

Рис. 3Когда Claude ждёт разрешения, карточка всплывает в notch: Да, Нет или Всегда, не переключаясь в терминал.

В строке меню окна лимитов сменяются каждые три секунды, набор выбирается в настройках. Статистика показывает сессии, токены, календарь за год, историю лимитов и скрытую фоновую работу. Те же цифры уходят по Bluetooth LE на Клодометр — табло с электронной бумагой.

Рис. 4Панель лимитов: Claude, Codex, Grok и Coding Plan от Z.ai и Kimi в одном списке.

Приложение работает в песочнице и получает доступ только на чтение к папкам ~/.claude/projects и ~/.codex/sessions. Ключи API лежат на Mac в файле с правами 0600, сеть нужна только провайдерам, чьи ключи добавлены. Интерфейс на английском, русском и польском, по языку системы.

Исходники и сборка: github.com/kpeeem/agent-meter
